# 포트폴리오 · 자산과 수익률

개인·법인 / 증권사 / 계좌성격별 보유 현황을 집계하는 GitHub Pages 앱입니다. 기존 Cloudflare Worker와 PIN 인증을 그대로 사용합니다. 실제 보유 데이터와 PIN은 저장소에 포함하지 않습니다.

## 계산과 갱신

- 금액은 원화. 총 평가금액은 현금 포함, 평가수익률의 분모는 현금 제외 매입금액입니다.
- 순평가손익 = 투자자산 평가금액 − 매입금액 − 입력 제비용. 배당·실현손익·세금 등 제공되지 않은 값은 추정하지 않습니다.
- 같은 이름의 다른 코드·통화를 합산하지 않습니다. 코드 없는 종목은 보유행을 따로 표시합니다. 같은 계좌번호라도 소유자·증권사·계좌성격이 다르면 별도 계좌로 집계합니다.
- 거래정지는 기준 평가금액을 유지해 합계에 포함합니다. 수량은 소수점 보유분을 유지합니다.
- 종목시세와 해당 통화 환율을 함께 받은 해외 보유분만 재평가합니다. 미수신은 현재 평가금액과 기존 출처를 유지합니다.
- 최신 요청 성공 건수를 매번 새로 집계합니다. 과거 성공을 현재 성공으로 표시하지 않습니다.
- 60초 자동 갱신, 숨겨진 탭에서는 중지, 요청당 50개 심볼로 나눠 프록시의 심볼 상한을 준수합니다. 응답시간 제한과 중복 요청 방지를 적용합니다.
- 잠금은 요청·타이머·인메모리 보유 데이터·화면을 지웁니다. PIN은 탭의 sessionStorage에 저장하며 기존 localStorage PIN은 읽은 뒤 제거합니다.
- 실제 보유 데이터의 이름·금액·코드·계좌 문자열은 HTML에 넣기 전에 이스케이프합니다.
- 형식·금액 오류 행은 합계에서 제외하고 경고합니다. 비용 누락은 0원 가정임을 표시합니다. 불완전 데이터의 합계를 완전한 계좌 합계라고 단정하지 않습니다.

## 구조

`index.html`, `styles.css`, `app.js` — 화면. `pf-core.js` — 순수 계산. `demo.js` — 실제 보유와 무관한 가상 예시. `config.js` — 기존 API 주소. `worker/` — 연결된 Cloudflare Worker 소스. 다른 작업에서 추가된 국내 KR 심볼 경로를 보존하며, 이 화면 개선 작업에서는 Worker를 수정·재배포하지 않았습니다.

## 검증

```sh
node --test tests/core.test.cjs
node --check app.js
```

`tests/viewport.html`은 모바일 390px, 태블릿 768px, 데스크톱 1440px에서 예시 화면을 확인하는 수동 검증 페이지입니다.

16개 계산 테스트: 합계·현금·거래정지·계좌 식별·종목 식별·해외 환산·환율 누락·통화 불일치·시세 실패·금액 오류·비용 누락·기여도·소수점 수량·예시 검산·코드 대기값·잘못된 시세 응답·국내 KR 심볼과 밀리초 기준시각.

실계좌 검증은 기존 PIN으로 인증한 뒤 수행해야 합니다. 예시 버튼으로 보는 값은 실제 보유 현황이나 투자 추천이 아닙니다.
